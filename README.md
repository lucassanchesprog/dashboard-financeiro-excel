# 📊 Dashboard Financeiro - Excel

Projeto desenvolvido para controle de gastos mensais utilizando Excel.

## 📌 Sobre o projeto
Este projeto tem como objetivo organizar despesas pessoais e apresentar uma visão clara dos gastos através de um dashboard.

## 🚀 Funcionalidades
- Organização de despesas por categoria (Moradia, Saúde, Alimentação, Lazer e Investimento)
- Cálculo automático de subtotais e total geral
- Cálculo de saldo mensal
- Dashboard com gráfico de pizza para visualização dos gastos

## 🛠️ Ferramentas utilizadas
- Microsoft Excel

## 🎯 Objetivo
Praticar organização de dados, uso de fórmulas e análise de informações.
